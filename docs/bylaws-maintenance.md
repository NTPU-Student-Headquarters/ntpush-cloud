# 法規系統教學

最後更新：2026-05-14 by [Andy312432](https://github.com/Andy312432)

## 系統整體運作架構

現行法規系統由 Google Drive 共編資料夾 + [NTPU Legislative Database](https://github.com/ntpusu/legislative-data) + 本專案 + [Sync Plugin](https://github.com/ntpusu/regulation-sync-plugin) + WordPress 會網等五個系統組成。整體運作方式可參閱 [README](../README.md) 文件。

## 壹、法規文字檔維護：完全透過 Google Drive 操作

### SOP

請以各單位官方 Google 帳號登入後，找到 Google Drive 共用資料夾「學生自治會法規系統」，即可看到多個資料夾，裡面分別儲存各單位主管法規。請您只編輯自身單位主管法規。

在資料夾中，會有多個貴機關主管之法規文字檔（以下亦稱法規檔）。

法規檔名使用特定的四位數字。基本上，第一位數字代表機關，第二位數字代表法規粗分類，第三、四位數為流水號（但第二至四位數，只要不重複，貴機關可自行編列）。 **一部法規只會有一個 ID，且不可重複** ，如忘記編號對應到哪部法規，可[點此查看](https://raw.githubusercontent.com/ntpusu/legislative-data/refs/heads/main/data/bylaw-list.json)（按 Ctrl+F 可快速搜尋），或登入 LegiHub 後，點選左側選單「法規系統」再點「取得各式檔案」，該頁面就會列出。

法規使用 TXT 格式儲存，請確保副檔名是 `.txt` 。您可以使用 Windows 系統內建之「記事本」軟體來開啟。

* 修正法規：下載「法規 id.txt」檔案後，依據下述格式修改內容，上傳取代舊版本。
* 制定／訂定法規：製作一份「法規 id.txt」檔案，上傳到資料夾。
* 廢止法規：**請不要刪除原有法規檔**，而是比照修正法規，但請將「status: active」改為「status: abandoned」。另外，記得也要把廢止過程寫到沿革裡（參考寫法：[舊法規標準法](https://ntpusu.org/?p=588)）。

### 指定格式

為了方便系統判讀法規條號、章節標題、項次，以在會網瀏覽時顯示舒適的排版，請遵循以下格式來維護法規。

法規的格式分成在頂部、以 YAML 格式記錄的基本資料（以英文關鍵字開頭的那幾行），還有以純文字方式記錄的內文。

關於內文：

- 章節：請直接寫「第X章 標題」、「第X節 標題」，不需要加上任何特殊標記，但章節序號與章節標題本身請以一個全形或半形空白隔開。
- 條號：請直接寫「第X條」（支援阿拉伯數字與中文數字，但基於易讀考量，建議使用阿拉伯數字）。系統支援括註法條主旨，請以全形括號加註，例如 `第X條（主旨）`；當法條不撰寫主旨時，括號可以省略。
- 條文內容：每個「項」前面加一個全形空白「`　`」表示。「款」、「目」則會自動偵測以「`一、`」、「`（一）`」開頭的行，款、目**請不要以空格縮排**（若以空格縮排會造成錯誤）。

以下是內文部分的範例：

```yaml
第一章 總則
第1條
　跨校區自治事務之處理，依本條例之規定。
第2條
　本條例用詞，定義如下：
一、跨校區自治事務：指單一校區無自行處理權限之自治事務。
二、跨校區機關：指總會與學生法院。
第二章 財務
第一節 通則
第3條
　跨校區機關經費之收支與管理，依本章之規定。
……（下略）
```

關於基本資料（在每個檔案的頭部，以 YAML 格式儲存），各欄位說明如下：

- `titleFull`：法規標準法規定之全銜。
- `titleShort`：主管部門請賦予法規一個簡稱，不包含「國立臺北大學學生自治會」前綴，但如果是校區單行法規，建議冠上「三峽／臺北校區」前綴。
- `modifiedType`：請填制定／訂定／修正／廢止。
- `modifiedDate`：請以 YYYY-MM-DD 格式填寫。
- `status`：還有效力的法規請填「active」，若已廢止請填「status: abandoned」。
- `history`：
  - 每一行以短線加空格「`- `」開頭，接下來寫出修法沿革。
  - 每行的組成，以自治法律為例，是「O年O月O日立法機關XX會議通過，O年O月O日行政機關公布（發文字號），\[異動類別]\[異動範圍]。」
  - 例如「114年11月18日三峽校區學生議會第26屆第3次常會通過，會長11月29日公布（峽學字第1141129002號），修正第3條、第6條。」
  - 以議會自律規則為例：「114年7月29日三峽校區學生議會第26屆第2次預備會議通過，7月30日北大峽議授秘字第1140730010號公告公告，修正第3、4、6條條文。」

請記得在這些資料的前後加上 `---` 三個半形短線，這樣系統才能辨識出這是基本資料欄位。填寫範例可參看：

```yaml
---
titleFull: 國立臺北大學學生自治會三峽校區學生議會學生議員出缺席獎懲規則
titleShort: 三峽校區學生議員出缺席規則
modifiedType: 修正
modifiedDate: 2025-07-30
status: active
history: 
- 110年8月三峽校區學生議會第22屆第1次臨時會通過，修正部分條文。
- 114年7月29日三峽校區學生議會第26屆第2次預備會議通過，7月30日北大峽議授秘字第1140730010號公告公告，修正第3、4、6條條文。

---
第1條
　（下接內文）
```

## 貳、同步法規到 Legislative Database

簡單來說，儘管法規系統基本上是在本專案 (LegiHub) 操作，但本系統的資料是儲存在 [NTPU Legislative Database](https://github.com/ntpusu/legislative-data) 專案。

程式約每天凌晨 2 至 4 時間，會自動從 Google Drive 同步法規檔案到該專案儲存庫，順便當作備份。因此，請避免在該段時間內，於 Google Drive 操作法規維護。

如果您上傳新法規後，需要立刻使用，而不方便等到系統自動同步，可透過本 LegiHub 專案，手動即時同步，其操作方式如下：

首先，LegiHub 專案需要以各單位官方 Google 帳號登入，如果有換帳號請務必通知維護人員。

登入後，請點選左側選單「法規系統」再點「同步法規」，進入後點選中間藍色按鈕。

如果沒問題，系統應該會顯示一行帶有打勾 emoji 的文字說明，約 1 到 3 分鐘後，即同步完成（該則文字說明有個「執行情形請到 GitHub Actions 頁面查看」連結，點選可查看進度）。

## 參、在 LegiHub 取得各式法規檔案

法規資料同步後，使用者可在本 LegiHub 專案：

- 預覽會網上專門為了瀏覽法規設計的樣式（下稱會網樣式）、
- 下載修正條文對照表空白表格 DOCX 檔、
- 列印符合《中央法規標準法》的公告版 PDF 檔，或
- 複製會網樣式原始碼（如果在步驟「肆、」，想在會網採取手動嵌入）。

操作路徑：點選左側選單「法規系統」再點「取得各式檔案」，該頁面中點選您要的法規。

## 肆、讓法規顯示在會網法規資料庫上

法規系統是我們內部維護用的。若要呈現到會網法規資料庫，則需要另行處理。目前我們提供兩種方式，第一種是自動化的，一部法規只需要設定一次，未來所有修法均由系統抓取資料到會網上；第二種是每次修正時需手動操作。

### 方式一：設定 Sync

請登入[會網後台](https://ntpusu.org/enter-the-park)後，在左側選單點選［法規同步］。

第一次進入頁面時，應有一個步驟說明的介面說明如何使用，在此簡要說明操作步驟：

- （新增法規）步驟一：請新增一則文章（post），並將該篇文章的分類設定為「法規」下的任一分類。請勿直接設定為法規，或同時選擇母分類法規與子分類！
- 步驟二：回到「法規同步」頁面，找到［立即同步］區塊，在「1. 選擇法規來源」步驟，建議選擇［從法規清單選擇］，若有正確依照上面格式儲存 txt 檔案，應會在清單中看到先前步驟所新增的法規。
- 步驟三：立即同步區塊下滑至「2. 選擇要更新的內容」，選擇在上一步驟時新增的文章後，按下［立即同步］。
- 步驟四：此時，您可以在［已對應內容］找到已經對應之法規。請在您要同步的那個法規的那一列中，將 shortcode 欄的文字複製起來。
- 步驟五：請回到步驟一新增的文章，在裡面插入一個短代碼區塊，並將前一步驟複製的 shortcode 貼上去。

若正確設定，法規應會在每天固定同步。包含 Metadata 的日期等欄位，只要法規系統有處理，會網 Sync 功能均會自動辦理。

### 方式二：手動嵌入原始碼

首先，依照【參、在 LegiHub 取得各式法規檔案】的說明，從 LegiHub 複製會網樣式原始碼。

接著，到會網對應之文章，把所有區塊清除後，新增一個自訂 HTML 區塊，並將原始碼貼上。

請不要忘記修改右側 Metadata ，特別是日期。

確認無誤後即可發布。
